# 🚀 Smart App Uninstaller (Advanced Wireless Edition)
**Created by Ashik**

A powerful, hacker-style terminal tool to wirelessly remove annoying system apps (bloatware) from your Android device without Root! 

## ✨ Features
- **🔗 Wireless Debugging:** Connect directly via WiFi (No USB cable needed).
- **🗑️ Smart Search Logic:** Don't know the package name? Just type the app name (e.g., `netflix`, `miui`), and the tool will auto-detect and uninstall it!
- **⚡ 100% Safe & Rootless:** Uses Android's native PM (Package Manager) via user 0.
- **💻 Hacker-style UI:** Beautiful terminal interface with Figlet banners and perfectly aligned inputs.
